# AInvest CLI Agent 桌面应用 v1 PRD

## 1. 产品概述与背景

AInvest CLI Agent 是一款面向投资研究的桌面 Agent 工作台。它不是普通聊天窗口，而是一个可以调用工具、记录用户偏好、管理 session、辅助看行情/新闻/策略的投研助手。

**产品定位**：简约现代的金融投研平台，参考 Codex IDE 风格，强调工具化、专业化、可扩展性。

## 2. 本周 MVP 目标

完成一个可运行的 Electron 原型，重点验证以下四个核心假设：
1. **Agent 框架**：能否理解自然语言指令并做出合理响应
2. **工具调用**：能否正确调用各类投研工具并展示结果
3. **状态管理**：能否在多视图间保持状态一致性
4. **产品交互闭环**：用户输入 → Agent 理解 → 工具调用 → 结果展示 → 用户反馈，全流程跑通

## 3. 用户故事

### 用户故事 1：快速查询行情
> 作为投资者，我想要通过自然语言查询某只股票的实时行情，以便快速获取价格、涨跌幅、成交量等关键信息，而不需要打开多个金融网站。

**场景**：用户输入"查询贵州茅台今天行情"，Agent 识别意图，调用行情查询工具，在聊天面板旁展示行情卡片。

### 用户故事 2：获取相关新闻
> 作为投资者，我想要查询某只股票或行业的最新公告和新闻，以便及时了解影响股价的事件和动态。

**场景**：用户输入"最近有哪些关于新能源行业的新闻"，Agent 调用新闻检索工具，以时间轴形式展示新闻列表。

### 用户故事 3：管理多个研究会话
> 作为投资者，我想要同时跟踪多个股票或策略的研究进度，以便在不同投资标间快速切换，保持上下文连贯。

**场景**：用户创建"白酒研究"session，查询茅台、五粮液行情和新闻；再创建"新能源研究"session，查询宁德时代、比亚迪信息。通过右侧 session 列表快速切换。

### 用户故事 4：浏览行情总览
> 作为投资者，我想要在独立面板中浏览市场整体行情，以便快速了解大盘走势、热点板块和自选股动态，而不需要打开其他行情软件。

**场景**：用户打开应用后，左侧行情看板默认展示行情总览页，显示上证指数、深证成指等主要指数，以及自选股列表和热点新闻。用户可通过顶部导航切换视图。

### 用户故事 5：查看个股详情
> 作为投资者，我想要查看某只股票的详细行情和基本面信息，以便深入了解标的的投资价值。

**场景**：用户在自选股列表中点击"贵州茅台"，左侧行情看板切换到个股详情页，展示实时价格、涨跌幅、成交量、市值、PE/PB 等财务指标，以及相关新闻列表。

### 用户故事 6：个股联动交互
> 作为投资者，我想要在聊天中点击股票名称直接查看行情，以便根据 Agent 的分析建议快速验证和浏览相关标的。

**场景**：Agent 回复中提到"【贵州茅台】近期表现强劲"，用户点击聊天中的【贵州茅台】链接，左侧行情看板立即切换到贵州茅台的个股详情页。

## 4. 核心功能模块

### 4.1 Agent 对话交互
- **自然语言输入**：用户在底部输入框输入指令，支持 Enter 发送
- **消息类型**：
  - 用户消息（右侧气泡，深色背景）
  - Agent 文本回复（左侧气泡）
  - Agent 思考过程（可折叠的灰色小字，显示意图识别和工具选择逻辑）
  - 工具调用卡片（内嵌在对话中，展示调用的工具和参数）
  - 工具结果展示（行情卡片、新闻列表、图表等）
- **快捷指令栏**：输入框上方提供独立快捷指令栏，包含"/行情"、"/新闻"、"/策略"等投研类快捷指令，以及"/新建会话"、"/切换会话"等 Session 管理类快捷指令。点击后自动填充到输入框或执行对应操作
- **加载状态**：Agent 处理时显示打字机动画

### 4.2 工具调用框架
Agent 可调用以下工具（v1 均为 mock）：

| 工具 ID | 名称 | 功能 | 入参示例 | 出参示例 |
|---------|------|------|----------|----------|
| `market.query` | 行情查询 | 查询股票实时行情 | `{ symbol: "600519.SH" }` | 价格、涨跌幅、成交量、市值等 |
| `news.search` | 新闻检索 | 搜索股票/行业相关新闻 | `{ keyword: "新能源", limit: 5 }` | 新闻标题、摘要、来源、时间 |
| `strategy.backtest` | 策略回测 | 对简单策略进行回测 | `{ strategy: "MA5交叉", symbol: "000001.SZ" }` | 收益率、最大回撤、交易信号 |
| `stock.profile` | 股票档案 | 查询公司基本信息 | `{ symbol: "600519.SH" }` | 所属行业、主营业务、财务概要 |

**工具调用展示**：
- 在对话中以内联卡片形式展示"正在调用 [行情查询]..."
- 结果以结构化卡片展示（行情用数字面板、新闻用时间轴、策略用简单图表）

### 4.3 用户偏好管理
- **偏好设置面板**：通过左侧边栏或顶部菜单进入
- **可配置项**：
  - 主题模式（深色/浅色，默认深色，参考 Codex 风格）
  - 默认市场（A股/港股/美股）
  - 行情刷新频率（仅展示，v1 不实际刷新）
  - 语言偏好（中文/英文）
- **持久化**：使用 localStorage 保存，重启后恢复

### 4.4 Session 管理
- **多 Session 支持**：右侧边栏（占主界面 20%）展示 Session 列表
- **Session 属性**：名称、创建时间、最后活动时间、关联的股票代码列表
- **操作**：新建、重命名、删除、切换 Session
- **持久化**：Session 列表和每个 Session 的聊天记录保存到本地文件（JSON 格式，存储在应用用户数据目录）
- **当前 Session 状态**：切换 Session 时，聊天内容、上下文完全恢复

### 4.5 行情看板
行情看板位于主界面左侧（占 40%），与中央聊天面板、右侧 Session 列表形成三栏布局。行情看板为独立功能区域，支持视图切换和与聊天区域的个股联动交互。

#### 4.5.1 行情总览页
默认展示页面，参考主流行情网站首页设计：
- **指数概览区**：展示上证指数、深证成指、创业板指等主要指数，显示当前点数、涨跌幅、涨跌额
- **热点新闻区**：展示 5-8 条最新财经新闻简要标题，点击可在新窗口或侧边展开详情
- **自选股列表**：展示用户关注的股票，每行显示股票名称、代码、最新价、涨跌幅、涨跌额
- **板块涨幅排行**（Nice-to-have）：展示涨幅靠前的行业板块，显示板块名称和涨幅百分比

#### 4.5.2 个股详情页
通过点击自选股列表中的股票、或点击聊天中的个股链接后展示：
- **股票基本信息**：名称、代码、所属行业、主营业务简介
- **实时行情数据**：当前价格、涨跌幅、涨跌额、成交量、成交额、市值、换手率
- **相关新闻列表**：该股票相关的最新 5-10 条新闻标题及发布时间
- **简要财务指标**：PE（市盈率）、PB（市净率）、EPS（每股收益）等关键指标

#### 4.5.3 行情看板切换交互
- **总览页 → 个股页**：
  - 点击自选股列表中的任意股票
  - 点击聊天区域中 Agent 回复包含的【个股名称/代码】链接（如【贵州茅台】或【600519.SH】）
- **个股页 → 总览页**：
  - 点击个股详情页顶部的"返回"按钮
  - 点击顶部导航栏的"行情总览"标签
- **视图状态记忆**：切换 Session 时，行情看板的当前视图状态（总览/个股、当前查看的个股代码）应被记录并在返回时恢复

#### 4.5.4 个股联动交互流程
```
Agent 回复中包含【个股名称/代码】（如【贵州茅台】或【600519.SH】）
        ↓
聊天面板将该文本渲染为可点击链接（带下划线/特殊颜色标识）
        ↓
用户点击链接
        ↓
触发全局事件/状态更新，通知行情看板切换至对应个股
        ↓
行情看板从当前视图（总览或其他个股）切换到目标个股详情页
        ↓
个股详情页加载该股票的行情数据、新闻、财务指标
        ↓
用户在行情看板查看详情，同时在聊天面板继续对话（互不阻塞）
```

**未来扩展性（v1 预留，不实现）**：
- 支持从行情看板拖拽股票信息到聊天窗口，作为对话 context
- 支持在行情看板右键股票发送到当前 Session

## 5. 状态管理方案

**选用 Zustand**

理由：
- 本项目状态相对集中（当前 session、消息列表、用户偏好、工具调用状态）
- Zustand 轻量、无样板代码、TypeScript 支持好
- 适合 Electron 渲染进程，不需要中间件即可满足需求

**Store 划分**：
- `useSessionStore`：当前 session ID、session 列表、切换/增删 session
- `useChatStore`：当前 session 的消息列表、发送消息、追加消息
- `usePreferenceStore`：主题、语言、默认市场等用户偏好
- `useToolStore`：当前正在调用的工具、调用结果缓存

## 6. 数据持久化方案

**分层持久化**：

| 数据类型 | 存储方式 | 理由 |
|----------|----------|------|
| 用户偏好 | localStorage | 轻量、读取频繁、无需复杂查询 |
| Session 元数据（列表、名称、时间） | 本地 JSON 文件 | 结构简单，便于用户手动备份 |
| Session 聊天记录 | 本地 JSON 文件（按 session 分文件） | 可能较大，分文件避免单文件膨胀 |

**存储路径**：Electron `app.getPath('userData')/ainvest/sessions/`

v1 不使用 SQLite，以降低复杂度。若后续版本数据量大或需要查询能力，可迁移至 SQLite。

## 9. 产品交互闭环定义

**闭环流程**：

```
用户输入自然语言指令
        ↓
Agent 意图识别（显示"正在理解..."）
        ↓
Agent 决定是否需要工具调用
        ↓
如需工具 → 显示"正在调用 [工具名]..."
        ↓
执行 Mock 工具调用
        ↓
结果结构化展示（卡片/列表/图表）
        ↓
Agent 生成总结性回复
        ↓
用户查看结果并继续输入（新一轮闭环）
```

**关键交互细节**：
1. **即时反馈**：用户发送消息后，立即在聊天区显示用户消息，同时 Agent 显示"正在输入"状态
2. **思考过程可见**：Agent 的意图识别和工具选择逻辑以灰色小字显示，可折叠，增加用户信任感
3. **工具调用透明**：明确告知用户正在调用什么工具、传入什么参数
4. **结果内嵌**：工具结果直接内嵌在对话流中，不需要跳转页面
5. **错误处理**：工具调用失败时，展示友好错误信息，并提供重试按钮

## 10. 验收标准

### 10.1 Agent 对话交互
- [ ] 用户可以在输入框输入文字并按 Enter 发送
- [ ] 用户消息立即显示在聊天区域右侧
- [ ] Agent 回复显示在左侧，包含文本内容
- [ ] Agent 处理期间显示打字机/闪烁光标动画
- [ ] 快捷指令按钮点击后自动填充输入框前缀
- [ ] 聊天内容在 Session 切换时正确恢复

### 10.2 工具调用框架
- [ ] Agent 能识别至少 3 种意图（行情查询、新闻检索、策略回测）
- [ ] 识别意图后显示工具调用卡片
- [ ] Mock 数据正确返回并展示

## 11. 非功能需求

### 11.1 性能
- 首屏加载时间 < 3 秒
- 消息发送到 Agent 首次响应 < 500ms（Mock 场景）
- Session 切换 < 200ms
- 支持单 Session 至少 100 条消息不卡顿

### 11.2 Mock 数据要求
- 行情数据：至少覆盖 10 只A股常见股票（茅台、五粮液、宁德时代、比亚迪等）
- 新闻数据：每个关键词至少返回 3-5 条模拟新闻
- 策略回测：至少支持 1 种简单策略（MA5 交叉），返回固定格式的结果
- Mock 数据需有合理的随机波动（价格每次查询可有小额变化），增加真实感

### 11.3 安全
- 遵循 Electron 安全规范：启用 contextIsolation、禁用 nodeIntegration
- Preload 脚本最小暴露原则
- IPC 通道使用命名空间前缀

### 11.4 可访问性
- 支持键盘操作（Enter 发送、Esc 关闭弹窗、Tab 切换焦点）
- 颜色对比度符合 WCAG AA 标准
