## 一、产品概述

### 1.1 背景与问题

v6.0.1 的浏览器自动化采用**文本提取模式**：打开页面 → `innerText` 截取 → 返回文本。这解决"快速查一下"的场景，但存在根本性限制：

| 问题 | 示例 |
|------|------|
| **无法进入二级页面** | "去东方财富查中际旭创的研报" → 只拿到搜索结果列表文本，**看不到研报正文** |
| **无法理解页面结构** | Agent 不知道页面上有哪些可交互元素（按钮、链接、表单） |
| **无法与页面交互** | 无法点击、输入、滚动，对于需要操作的页面完全无能为力 |
| **信息定位粗放** | 8000 字符截断 + 噪声正则，无法精确提取特定区域内容 |

客户反馈明确提到："没有 DOM/Accessibility tree、浏览器控制"，这是核心缺口。

### 1.2 解决方案

新增**智能操作模式**（Agent Mode），与现有**文本提取模式**（Extract Mode）并行：

```
┌──────────────────────────────────────────────────┐
│  输入框旁 Toggle：[文本提取 ● │ ○ 智能操作]      │
└──────────────────────────────────────────────────┘
```

- **文本提取模式**（默认，当前行为不变）：打开 → innerText → 关闭，1-3 秒完成
- **智能操作模式**（新增）：Agent 可观察页面结构、点击链接、输入文本、滚动加载，深入获取信息

### 1.3 目标

1. 用户可一键切换浏览器操作模式
2. 智能操作模式下，Agent 能点击搜索结果进入二级页面
3. 智能操作模式下，Agent 能在页面上输入搜索关键词
4. 智能操作模式下，Agent 能滚动页面加载更多内容
5. 安全：所有操作在白名单域名内，Agent 不可执行危险操作
6. 成本可控：步数限制 + 超时限制，防止 Token 爆炸

## 三、功能规格

### 3.1 模式切换 Toggle

**位置**：输入框与发送按钮之间，发送按钮正上方

**样式**：
```
 ┌───────────────────────────────────┐
 │  [textarea 输入框]                 │
 │                                   │
 └───────────────────────────────────┘
 🌐 提取  ━━━●━━━  🤖 操作    [发送→]
```

- 左侧"提取"= 文本提取模式（默认选中）
- 右侧"操作"= 智能操作模式
- 图标 + 文字，紧凑不占额外行高
- 选中状态通过 `usePreferenceStore.browserMode` 持久化

**交互**：
- 点击切换，立即生效，无需确认
- 鼠标悬停显示 tooltip："文本提取：快速获取页面文本（默认）"/"智能操作：Agent 可点击/输入/滚动，深入获取信息"
- 发送消息时读取当前模式，传入 Agent Engine

### 3.2 智能操作模式行为

#### 3.2.1 Agent Loop 流程

```
用户输入 → 意图识别(web.browse) → 构造搜索 URL → 打开页面
  │
  ├── [Step 1] 获取 Accessibility Tree（AXTree）
  │     └── 简化树 → 传给 LLM
  │
  ├── [Step 2] LLM 决策下一步动作
  │     ├── click(nodeId) — 点击指定元素
  │     ├── type(nodeId, text) — 在元素中输入文本
  │     ├── scroll(direction) — 滚动页面
  │     ├── extract() — 提取当前页面文本作为最终结果
  │     └── done() — 已获取目标信息，结束操作
  │
  ├── [Step 3] 执行动作，返回结果
  │
  └── 重复 Step 1-3，直到 LLM 选择 extract/done 或达到步数上限
       │
       └── 提取最终内容 → LLM 生成回复
```

#### 3.2.2 Accessibility Tree 简化

原始 AXTree 可能有数千节点，需精简后传给 LLM：

**过滤规则**：
- 排除 `role: "generic"` / `"presentation"` / `"none"` 的无语义节点
- 排除 `visible: false` / `offscreen` 的不可见节点
- 最多保留 50 个节点（按可见性 + 交互性排序）
- 每个节点只保留：`nodeId`、`role`、`name`、`value`（如有）

**简化后示例**：
```json
[
  { "nodeId": "t1", "role": "textbox", "name": "搜索关键词" },
  { "nodeId": "b1", "role": "button", "name": "搜索" },
  { "nodeId": "l1", "role": "link", "name": "中际旭创：2024Q3业绩超预期" },
  { "nodeId": "l2", "role": "link", "name": "中际旭创深度报告：光模块龙头..." },
  { "nodeId": "l3", "role": "link", "name": "中际旭创(300308)个股资讯" }
]
```

#### 3.2.3 LLM 决策 Prompt

每步给 LLM 的信息：
1. 用户原始问题
2. 当前页面 URL 和标题
3. 简化的 AXTree
4. 已执行的操作历史
5. 可选 action 列表：`click` / `type` / `scroll` / `extract` / `done`

LLM 返回 JSON：
```json
{ "action": "click", "nodeId": "l1", "reason": "点击第一条研报链接查看详细内容" }
```

#### 3.2.4 安全约束

| 约束 | 规则 |
|------|------|
| 域名 | 仍受白名单限制，Agent 操作不可导航到白名单外域名 |
| 危险按钮 | 禁止点击 name 含"登录/注册/下载/购买/支付/删除"的元素 |
| 步数上限 | 单次浏览任务最多 5 步操作（不含初始打开） |
| 总超时 | 30 秒总超时（从首次打开页面开始计时） |
| 窗口复用 | 同一轮对话中的浏览器操作复用同一窗口，操作结束后关闭 |

### 3.3 文本提取模式行为

与 v6.0.1 完全一致，不改动：

- 打开页面 → SPA 智能轮询 → `innerText.slice(0,8000)` → 噪声过滤 → 返回
- 1-3 秒完成
- 不需要 CDP debugger

## 五、非功能需求

| 需求 | 标准 |
|------|------|
| 文本提取模式性能 | 不退化，1-3 秒完成 |
| 智能操作模式简单任务 | 10 秒内完成（2-3 步操作） |
| 智能操作模式复杂任务 | 30 秒内完成（5 步操作上限） |
| AXTree 精简 | 传给 LLM 的节点数 ≤ 50 |
| 体积增量 | 0（CDP 是 Electron 内置） |
| 内存增量 | BrowserWindow 复用，无明显增加 |

## 六、范围说明

### 本迭代包含（In Scope）

- 输入框旁模式切换 Toggle
- CDP Accessibility Tree 提取 + 简化
- Agent Loop（observe → think → act）
- 基础 action：click、type、scroll、extract、done
- 步数/超时限制
- 危险按钮过滤
- ThinkingBlock 步骤展示

### 本迭代不包含（Out of Scope）

- 白名单动态增删（v6.1 已有计划）
- 多模态记忆（截图、PDF 关联）
- 浏览器窗口可视化展示（Agent 操作过程不可见）
- 表单自动填充（登录等）
- 跨域 Cookie/Session 管理
- 文件下载
- API Key 加密存储

## 七、风险

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|---------|
| CDP 编码问题回归 | 中 | 高 | v6.0.1 因 `Runtime.evaluate` 乱码改用 `executeJavaScript`；AXTree 走 `Accessibility.getFullAXTree`，需验证无同类问题 |
| Agent 死循环 | 中 | 高 | 硬性步数上限 5 步 + 30 秒超时 |
| AXTree 节点过多 Token 爆炸 | 中 | 中 | 简化树 ≤ 50 节点，每步 LLM 调用成本可控 |
| LLM 决策质量不稳定 | 中 | 中 | 限制可选 action 类型，Prompt 约束，超限降级 |
| 用户误开启操作模式 | 低 | 低 | 默认"提取"模式，操作模式有 Tooltip 说明 |
