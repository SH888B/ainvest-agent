# AInvest Agent v4 PRD

> 版本：v4.0.0
> 日期：2026-06-06
> 状态：需求评审中

---

## 一、产品概述

AInvest Agent v4 在 v3 可观测性和体验优化的基础上，聚焦**行情看板内容升级**、**对话体验完善**和**视觉层次感提升**。核心目标：让左侧行情看板真正具备投研信息密度，让聊天交互更自然（Markdown 渲染、持久化可靠），让三栏布局视觉不单调。

---

## 二、版本目标

**"看板有料、对话可信、界面有层次"** —— 左侧行情看板从简单卡片升级为指数+统计+板块的投研仪表台；聊天回复支持 Markdown 富文本；Session 消息持久化可靠；三栏背景色差异化。

---

## 三、用户故事

### US-401：我想在行情看板看到更丰富的市场信息
> 作为用户，当我打开左侧行情看板的"总览"页时，我希望看到主要美股指数（道琼斯、纳斯达克、标普500）的点位和涨跌，以及市场涨跌分布统计和热点板块排行，这样我能快速感知市场整体情绪。

### US-402：我想看到更多港美股的行情数据
> 作为用户，我希望行情看板支持腾讯控股、阿里巴巴、英伟达等港美股标的的 Mock 行情和档案，这样我能在一个工作台里跟踪多市场持仓。

### US-403：我想在个股详情看到走势可视化
> 作为用户，当我查看某只股票的个股详情时，我希望在基本面信息下方看到该股票的走势图（模拟 K 线/折线），这样我能直观判断近期趋势。

### US-404：我重启应用后对话内容不能丢
> 作为用户，当我重启应用后，我希望能看到之前每个 Session 里的完整对话记录，而不只是 Session 名称。目前只有名称被保存，消息列表丢失了。

### US-405：我想让 Agent 回复支持富文本格式
> 作为用户，当 Agent 回复中包含加粗、列表、代码块等 Markdown 格式时，我希望这些内容能被正确渲染，而不是以纯文本形式展示原始标记符号。

### US-406：我不想三栏背景看起来像一个整块
> 作为用户，当我扫视整个应用界面时，我希望左侧行情看板、中间聊天面板、右侧 Session 列表三栏有微妙的背景色差异，帮助我快速区分功能区域。

### US-407：我想有一个明显的入口打开 DevTool 看板
> 作为开发者/测试人员，我想在智能助手面板顶部找到一个明显的按钮来打开/关闭 Agent 日志看板，而不需要记忆快捷键。

**验收标准**：

### 4.5 Session 消息持久化（Bugfix）

**问题描述**：
当前 `useSessionStore` 已使用 `zustand/persist` 将 Session 元数据（名称、ID、时间）保存到 localStorage，但 `useChatStore` 未做持久化。导致重启应用后，Session 列表可见，但点进去消息为空。

**修复方案**：
- 为 `useChatStore` 添加 `zustand/persist` 中间件
- persist key 独立命名，如 `ainvest:chatMessages`
- 持久化字段：`messagesBySession`（不需要持久化 `isLoading`，重启后应为 false）

**数据迁移/兼容**：
- 首次启用 persist 时，旧数据不存在，行为与当前一致（空消息），无破坏性变更
- 后续用户发送消息后，自动保存

**验收标准**：
- [ ] 发送消息、Agent 回复后，重启应用，该 Session 的消息完整保留
- [ ] 新建 Session、切换 Session、删除 Session 后，消息状态与 Session 状态一致
- [ ] 清除浏览器/应用存储后，应用可正常运行（无崩溃）

### 4.6 智能助手回复 Markdown 渲染（Frontend Optimization）

**功能描述**：
将 Agent 回复文本从纯文本 `whitespace-pre-wrap` 渲染升级为 Markdown 富文本渲染。

**支持的 Markdown 语法**：
- 加粗（`**text**`）
- 斜体（`*text*`）
- 无序列表（`- item` / `* item`）
- 有序列表（`1. item`）
- 行内代码（`` `code` ``）
- 代码块（```` ``` ````）
- 引用（`> text`）
- 链接（`[text](url)`）
- 段落与换行

**样式要求**：
- 整体字体大小保持 13px/14px，与当前一致
- 加粗文字使用 `text-text`（纯白），与正文区分
- 列表项左侧留出合理缩进
- 代码块背景使用 `bg-background`，边框使用 `border`，圆角
- 引用块左侧使用 `border-l-2 border-primary`

**注意事项**：
- 用户消息保持原样（纯文本即可，用户通常不会输入复杂 Markdown）
- 工具调用卡片、Thinking 块不受此变更影响

**验收标准**：
- [ ] Agent 回复中的 `**text**` 正确渲染为加粗
- [ ] 列表语法正确渲染为带缩进的列表
- [ ] 代码块正确渲染为等宽字体+深色背景
- [ ] 链接可点击，在新标签页打开
- [ ] 纯文本回复不受负面影响

---

### 4.7 三栏背景色微调（Frontend Optimization）

**功能描述**：
当前三栏（行情看板 40%、聊天面板 40%、Session 列表 20%）均使用同一背景色，视觉上缺乏分区感。需要对三栏背景色进行微妙的差异化处理。

**设计方向（供设计确认，PM 建议方案）**：

| 区域 | 当前背景色 | 建议背景色 | 说明 |
|------|-----------|-----------|------|
| 行情看板（左） | `#0f1117` | `#0c0e14` | 稍深，强调信息面板 |
| 聊天面板（中） | `#0f1117` | `#0f1117` | 保持原色，作为视觉基准 |
| Session 列表（右） | `#0f1117` | `#12141c` | 稍浅，与左侧形成对比 |

**实现方式**：
- 不改动 `tailwind.config.js` 的 `background` 主色值
- 在 `MainLayout.tsx` 的三栏容器上分别添加自定义背景色类或使用 inline style
- 如需新增 Tailwind 自定义色值，在 `tailwind.config.js` 的 extend 中添加

**验收标准**：
- [ ] 三栏背景色不完全相同，肉眼可感知微妙差异
- [ ] 差异克制，不破坏整体深色主题的一致性
- [ ] 所有卡片（bg-surface）在三栏上均可正常显示，无色彩冲突

### 4.8 DevTool 看板显式开关（UX Optimization）

**功能描述**：
当前 DevTool Agent 日志面板只能通过快捷键 `Ctrl+Shift+L` 唤起，用户不易发现。需要在聊天面板顶部增加一个显式的扳手图标按钮作为开关。

**入口设计**：
- 位置：聊天面板顶部栏，设置按钮（齿轮图标）的左侧或右侧
- 图标：扳手图标（`Wrench` from lucide-react）
- 样式：与设置按钮一致（`text-text-muted hover:text-text`）
- 可见性：仅在开发环境（`import.meta.env.DEV`）下显示
- 行为：点击后 toggle DevTool 面板的打开/关闭状态

**与现有快捷键的兼容性**：
- 保留 `Ctrl+Shift+L` 快捷键功能不变
- 按钮状态和快捷键状态保持同步

**验收标准**：
- [ ] 开发环境下，聊天面板顶部可见扳手按钮
- [ ] 点击按钮可打开 DevTool 面板
- [ ] 再次点击可关闭 DevTool 面板
- [ ] 生产环境（非 DEV）下按钮不显示
- [ ] 快捷键 `Ctrl+Shift+L` 功能不受影响

## 五、交互流程

### 5.1 行情看板总览浏览流程

```
用户打开应用
  ↓
左侧行情看板默认展示"总览"页
  ↓
【指数看板】道琼斯 42150.30  +0.42%
            纳斯达克 18230.15  +0.88%
            标普500   5875.20  +0.56%
  ↓
【涨跌分布图】横向柱状图展示各区间的股票数量
  ↓
【行业板块】涨幅 Top 5 / 跌幅 Top 5
  ↓
用户滚轮向下浏览更多内容
```

### 5.2 个股详情查看流程

```
用户在总览页或自选股列表点击某只股票
  ↓
行情看板切换到"个股详情"页
  ↓
展示头部行情信息（价格、涨跌）
  ↓
展示基本面指标（PE、PB、成交量、市值等）
  ↓
展示公司档案（行业、CEO、成立时间、简介）
  ↓
【新增】展示 30 日走势图（折线图/面积图）
  ↓
用户可继续向下滚动查看完整内容
```

### 5.3 重启后恢复对话流程（Bugfix 后）

```
用户发送消息 → Agent 回复
  ↓
消息自动保存到 localStorage（ainvest:chatMessages）
  ↓
用户关闭应用
  ↓
用户重新打开应用
  ↓
Session 列表加载（已有行为）
  ↓
ChatStore 从 localStorage 恢复 messagesBySession
  ↓
用户点击某 Session → 消息列表正确展示
```

| recharts 引入增加包体积 | 打包体积变大 | 仅使用 LineChart/BarChart/AreaChart，按需引入 |
| Markdown 渲染与流式追加冲突 | 频繁 re-render 导致性能问题 | 使用轻量库，或流式完成后再渲染 Markdown |
| localStorage 消息量过大 | 单 Session 消息多可能超限 | 后续迭代考虑 IndexedDB 替换 |
| 三栏色差设计过强 | 破坏整体深色主题一致性 | 色差控制在 5% 以内，保持专业感 |

## 十二、附录

### 决策记录

| 决策项 | 选择 | 原因 |
|--------|------|------|
| 指数看板范围 | 美股三大指数 | 用户明确指定道琼斯/纳斯达克/标普500 |
