# AInvest v4.1 UI 视觉升级 技术架构文档

> 版本：v4.1.0
> 日期：2026-06-06
> 状态：已评审
> 依据：`docs/prd/v4.1-prd.md`

---

## 一、技术目标

在不引入任何新依赖、不改变业务逻辑的前提下，完成视觉体系升级：
1. Tailwind CSS 主题 token 全面重构（15 个色值变更 + 3 个新增）
2. 全局样式层升级（滚动条、selection、基础 transition）
3. 关键组件玻璃态改造（6+ 个组件）
4. 数字字体规范化

---

## 二、关键决策

| # | 决策项 | 选择 | 理由 |
|---|--------|------|------|
| 1 | 玻璃态实现方式 | Tailwind `backdrop-blur-sm` + `bg-opacity` 组合 | 不引入新库，性能可控，Tailwind 原生支持 |
| 2 | 色值降级策略 | CSS 变量降级 | 如 blur 性能不佳，直接替换为实色 `bg-surface` |
| 3 | 图表主题隔离 | recharts stroke/fill 使用硬编码色值 | 不依赖 Tailwind token，避免 token 变更导致图表断裂 |
| 4 | 字体加载 | 系统字体栈（Inter / JetBrains Mono via fontFamily） | 不引入 CDN 字体，避免网络依赖 |
| 5 | 动效实现 | 纯 CSS transition（`transition-colors duration-150`） | 不引入 Framer Motion，保持零依赖增量 |

## 三、Tailwind 主题扩展方案

### 3.1 Color Token 映射表

```javascript
// tailwind.config.js - theme.extend.colors 最终形态
{
  background: '#030712',
  'panel-left': '#080d1a',
  'panel-center': '#0B1120',
  'panel-right': '#0e1526',
  surface: {
    DEFAULT: '#111827',
    elevated: '#1a2236',
    hover: '#1e293b',
  },
  border: {
    DEFAULT: '#1e293b',
    subtle: '#172033',
  },
  primary: {
    DEFAULT: '#2563eb',
    hover: '#1d4ed8',
  },
  text: {
    DEFAULT: '#f1f5f9',
    secondary: '#94a3b8',
    muted: '#64748b',
  },
  success: '#10b981',
  warning: '#f59e0b',
  danger: '#f43f5e',
}
```

### 3.2 Token 语义化说明

| Token | 用途 | 使用场景 |
|-------|------|---------|
| `background` | 全局最底层 | 极少直接使用，主要供 CSS reset |
| `panel-left` | 行情看板背景 | `MarketPanel` 根容器 |
| `panel-center` | 聊天面板背景 | `ChatPanel` 根容器 |
| `panel-right` | Session 侧边栏背景 | `SessionSidebar` 根容器 |
| `surface` | 卡片背景（默认） | `bg-surface` 用于实体卡片 |
| `surface/80` | 卡片背景（玻璃态） | `bg-surface/80 backdrop-blur-sm` 组合 |
| `surface-elevated` | 悬浮态卡片 | 选中态 Session 项、hover 态卡片 |
| `surface-hover` | Hover 态背景 | hover 过渡目标色 |
| `border` | 主边框 | 三栏分隔线、卡片边框 |
| `border-subtle` | 极淡边框 | 玻璃态卡片边框，降低视觉重量 |
| `text` | 主文字 | 标题、正文、用户消息 |
| `text-secondary` | 次要文字 | 副标题、描述 |
| `text-muted` | 禁用文字 | placeholder、禁用态 |

### 3.3 迁移注意事项

- `surface-hover` 原值为 `#232633`，新值为 `#1e293b` —— 差异微小，不影响语义
- `border` 原值为 `#2a2e3b`，新值为 `#1e293b` —— 边框变深，需注意对比度
- `text` 原值为 `#e2e8f0`，新值为 `#f1f5f9` —— 纯白程度微增

## 四、全局样式层方案

### 4.1 文件：`src/renderer/index.css`

**新增内容**（插入到现有 Tailwind directives 之后）：

```css
@layer base {
  /* 滚动条 - 极细、深色、与背景融合 */
  * {
    scrollbar-width: thin;
    scrollbar-color: theme('colors.surface.elevated') transparent;
  }
  *::-webkit-scrollbar {
    width: 6px;
    height: 6px;
  }
  *::-webkit-scrollbar-track {
    background: transparent;
  }
  *::-webkit-scrollbar-thumb {
    background-color: theme('colors.surface.elevated');
    border-radius: 3px;
  }
  *::-webkit-scrollbar-thumb:hover {
    background-color: theme('colors.border.DEFAULT');
  }

  /* 文本选中态 */
  ::selection {
    background-color: theme('colors.primary.DEFAULT / 30%');
    color: theme('colors.text.DEFAULT');
  }

  /* 基础过渡 - 所有颜色属性默认 150ms */
  * {
    @apply transition-colors duration-150;
  }
}
```

### 4.2 技术约束

- `@layer base` 确保样式优先级低于 Tailwind utilities，可被覆盖
- `scrollbar-color` 为 Firefox 标准，`::-webkit-scrollbar` 为 WebKit（Electron 内置 Chromium 支持）
- `* { transition-colors }` 对性能影响极小（仅 color 相关属性），不触发布局重排

## 五、玻璃态组件规范

### 5.1 标准类名组合

```
bg-surface/80 backdrop-blur-sm border border-border-subtle rounded-lg
hover:bg-surface-hover hover:border-border transition-all duration-150
```

### 5.2 使用场景矩阵

| 组件 | 是否使用玻璃态 | 类名组合 | 理由 |
|------|--------------|---------|------|
| `IndexCard` | 是 | 标准组合 | 行情卡片是高频视觉焦点 |
| `MessageItem`（Agent） | 是 | 标准组合 | 聊天内容是核心交互区 |
| `MessageItem`（User） | 否 | `bg-surface` 实色 | 用户消息不需强调 |
| `SessionSidebar` 行项 | 是 | 标准组合 | 右侧列表需要空间层次感 |
| `StockDetail` 信息卡片 | 是 | 标准组合 | 个股详情页核心信息 |
| `StockChart` 容器 | 否 | `bg-surface` + `border` | recharts 内部已自包含视觉元素 |
| `MarketDistributionChart` 容器 | 否 | `bg-surface` | 图表容器不宜叠加 blur |
| `SectorLeaderboard` 行项 | 否 | `hover:bg-surface-hover` 纯 hover | 列表项数量多，全玻璃态过重 |

### 5.3 降级策略

如 `backdrop-blur-sm` 在目标设备上导致掉帧：

```
// 降级方案：移除 blur，仅保留半透明 + 边框
bg-surface/90 border border-border-subtle rounded-lg
hover:bg-surface-hover hover:border-border transition-all duration-150
```

> Developer 在自测阶段需验证滚动流畅度；如发现问题，Reviewer 可要求应用降级方案。

## 七、图表主题兼容性

### 7.1 关键原则

recharts 组件（`StockChart.tsx`、`MarketDistributionChart.tsx`）的 stroke/fill 使用**硬编码色值**，不引用 Tailwind token。因此 Tailwind 颜色重构不会影响图表渲染。

### 7.2 现有硬编码色值审计

| 组件 | 硬编码色值 | 是否与新 Token 冲突 |
|------|-----------|-------------------|
| `StockChart` | `'#22c55e'` / `'#ef4444'` | **冲突** - v4.1 新 success/danger 为 `#10b981` / `#f43f5e` |
| `MarketDistributionChart` | `'#22c55e'` / `'#ef4444'` / `'#6b7280'` | **冲突** - 同上 |
| 图表 Tooltip | `backgroundColor: '#1f2937'` / `border: '#374151'` | 无冲突，独立定义 |
| 图表轴线 | `stroke="#9ca3af"` / `stroke="#374151"` | 无冲突 |

### 7.3 处理方案

图表硬编码色值应同步更新为与新 token 一致：
- `'#22c55e'` → `'#10b981'`
- `'#ef4444'` → `'#f43f5e'`

> 此项由 Developer 在 M1.1 阶段同步完成。

## 八、性能规范

### 8.1 backdrop-blur 性能

| 强度 | GPU 开销 | 建议使用场景 | v4.1 使用 |
|------|---------|------------|----------|
| `blur-none` | 无 | 纯实色卡片 | 非玻璃态卡片 |
| `blur-sm` | 极低（单次 pass） | 一般卡片 | 玻璃态卡片 |
| `blur-md` | 中等（多次 pass） | 弹窗/浮层 | 不使用 |
| `blur-lg` | 高 | 模态背景 | 不使用 |

### 8.2 性能验收阈值

| 指标 | 阈值 | 验证方式 |
|------|------|---------|
| 滚动流畅度 | 60fps | 肉眼观察 + DevTools Performance |
| 首次渲染 | 无白屏/闪烁 | 启动应用观察 |
| hover 响应 | < 16ms | 肉眼无感知延迟即可 |

### 8.3 降级触发条件

如在以下任一测试中观察到卡顿：
- 消息列表滚动（>50 条消息）
- 行情看板总览页滚动（含 recharts 图表）
- Session 列表快速滚动（>20 个 Session）

Reviewer 可要求 Developer 将对应区域的 `backdrop-blur-sm` 降级为纯半透明 `bg-surface/90`。

## 十一、技术风险与应对

| 风险 | 等级 | 应对 |
|------|------|------|
| Tailwind `colors` 嵌套语法导致构建失败 | 低 | Tailwind v3 原生支持嵌套对象；如报错可展开为扁平结构 |
| `* { transition-colors }` 影响 recharts 动画 | 低 | recharts 动画使用 CSS transform/opacity，不受 color transition 影响 |
| `backdrop-blur-sm` 在低端 Windows 设备掉帧 | 低 | 自测验证；如掉帧应用降级方案 `bg-surface/90` |
| 旧 token 残留导致视觉不一致 | 中 | Reviewer 全局搜索旧色值 `#0f1117`、`#1a1d27`、`#2a2e3b`、`#3b82f6` |
