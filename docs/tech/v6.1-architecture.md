### 1.2 技术风险与缓解

| 风险 | 级别 | 缓解 |
|------|------|------|
| ~~CDP 编码问题回归~~ | ~~🔴~~ ✅ 已验证 | POC 结果：`Accessibility.getFullAXTree` 返回 JSON 结构化数据，不走字符串编码通道，**中文完全正常** |
| ~~CDP debugger 与 executeJavaScript 冲突~~ | ~~🟡~~ ✅ 已验证 | POC 结果：`debugger.attach()` 后 `executeJavaScript` **完全正常**，且 `Runtime.evaluate` 也恢复正常 |
| AXTree nodeId 无法映射到 DOM 域 | 🟡 已规避 | POC 结果：AXTree nodeId 与 DOM nodeId 是不同命名空间，`DOM.getBoxModel` 失败。**改用 executeJavaScript 定位坐标 + CDP Input 点击，绕过 nodeId 映射问题** |
| AXTree 节点过多 | 🟡 | 金融网站 AXTree 可达数千节点。简化过滤策略 + 50 节点硬上限缓解。 |
| LLM 决策不稳定 | 🟡 | 限定 action 类型 + JSON Schema 约束 + 超限降级。 |

### 1.3 POC 验证结果（2026-06-12）

#### POC-1: AXTree 中文验证 — ✅ 通过

- 测试页面：百度搜索"中际旭创"
- `Accessibility.getFullAXTree` 返回 **2345 个节点**
- 含中文节点 **874 个**，中文内容完全正确
- 交互元素 **154 个**（link、button、textbox 等）
- **关键发现**：AXTree 返回结构化 JSON，不经过字符串编码通道，因此不存在 v6.0.1 `Runtime.evaluate` 的中文乱码问题

#### POC-2: CDP + executeJavaScript 共存 — ✅ 通过

- `debugger.attach('1.3')` 后 `executeJavaScript` 完全正常
- `executeJavaScript` 返回中文正常，长度 500 字符
- **额外发现**：`Runtime.evaluate` 在 CDP attach 后中文也正常了！说明 v6.0.1 的乱码问题可能是未 attach debugger 时的 bug

#### POC-3: Click 方案验证

| 方案 | 结果 | 说明 |
|------|------|------|
| A. JS 定位 + CDP 点击 | ✅ 可行 | `executeJavaScript` 获取元素 `getBoundingClientRect()` 坐标 → CDP `Input.dispatchMouseEvent` 模拟点击。最可靠 |
| B. AXTree nodeId → DOM 域 | ❌ 不可行 | AXTree nodeId 与 DOM nodeId 是不同命名空间，`DOM.getBoxModel` 返回 `Invalid parameters` |
| C. 纯 JS `a.click()` | ✅ 可行 | 最简单，不需要 CDP。但 `a.click()` 可能被网站 `preventDefault` 拦截 |

### 1.4 最终技术选型

基于 POC 结果，采用**混合方案**（A+C 组合），完全绕开 AXTree → DOM nodeId 映射问题：

| 操作 | 实现方式 | 理由 |
|------|---------|------|
| **观察** | CDP `Accessibility.getFullAXTree` → 简化过滤 | 唯一可靠方式，中文正常 |
| **点击** | `executeJavaScript` 定位坐标 + CDP `Input.dispatchMouseEvent` | 模拟真实鼠标，不会被 `preventDefault` 拦截 |
| **输入** | `executeJavaScript` 聚焦 + CDP `Input.insertText` | CDP 输入更可靠 |
| **滚动** | CDP `Input.dispatchMouseEvent(mouseWheel)` | 最简单 |
| **提取文本** | `executeJavaScript` | 已验证与 CDP 共存，中文正常 |

**不需要** `DOM.getDocument`、`DOM.getBoxModel`、`DOM.resolveNode` 等 DOM 域命令

### 2.2 新增数据流

#### 文本提取模式（不变）

```
用户输入 → classifyIntent → extractToolArgs → executeTool('web.browse') → LLM 回复
```

#### 智能操作模式（新增）

```
用户输入 → classifyIntent → extractToolArgs(query/domain)
  → runBrowserAgentLoop(query, domain, config):
      ├── 1. buildSearchUrl → 主进程 browser:open
      ├── 2. 主进程 browser:attachCDP → 启用 CDP
      ├── 3. [LOOP] 最多 5 步：
      │     ├── browser:getAXTree → 简化 AXTree
      │     ├── LLM 决策 → action (click/type/scroll/extract/done)
      │     ├── 安全检查（危险按钮过滤 + 域名校验）
      │     ├── browser:{action} → 执行操作
      │     └── if extract/done → break
      ├── 4. 主进程 browser:detachCDP
      └── 5. 返回最终提取内容 → LLM 回复
```

#### 3.1.3 AXTree 获取与简化

```typescript
async getAXTree(): Promise<AXNode[]> {
  if (!this.cdpAttached) throw new Error('CDP not attached')

  // 1. 获取完整 AXTree
  const result = await this.window!.webContents.debugger.sendCommand(
    'Accessibility.getFullAXTree'
  )

  // 2. 简化：过滤 + 排序 + 截断
  const EXCLUDED_ROLES = new Set(['generic', 'presentation', 'none', 'Ignored', 'LineBreak'])
  const INTERACTIVE_ROLES = new Set(['button', 'link', 'textbox', 'combobox', 'searchbox', 'checkbox', 'radio', 'tab'])

  const nodes: AXNode[] = result.nodes
    .filter((n: any) =>
      !EXCLUDED_ROLES.has(n.role?.value) &&
      n.name?.value &&
      !n.properties?.some((p: any) => p.name === 'hidden' && p.value.value === true)
    )
    .map((n: any) => ({
      nodeId: n.nodeId,
      role: n.role?.value || 'unknown',
      name: n.name?.value || '',
      value: n.value?.value || undefined,
    }))
    .sort((a: AXNode, b: AXNode) => {
      // 交互元素优先
      const aInteractive = INTERACTIVE_ROLES.has(a.role) ? 0 : 1
      const bInteractive = INTERACTIVE_ROLES.has(b.role) ? 0 : 1
      return aInteractive - bInteractive
    })
    .slice(0, 50)  // 硬上限 50 节点

  return nodes
}
```

#### 3.1.4 点击实现

```typescript
async clickElement(nodeId: string): Promise<{ success: boolean; error?: string }> {
  if (!this.cdpAttached) return { success: false, error: 'CDP not attached' }

  // 1. 获取元素在视口中的位置
  const { node } = await this.window!.webContents.debugger.sendCommand(
    'DOM.describeNode', { nodeId }
  )
  
  // 2. 获取元素 bounding box
  const { model } = await this.window!.webContents.debugger.sendCommand(
    'DOM.getBoxModel', { nodeId }
  )
  
  if (!model?.content) return { success: false, error: 'Element not visible' }
  
  const x = (model.content[0] + model.content[2]) / 2
  const y = (model.content[1] + model.content[5]) / 2
  
  // 3. 模拟鼠标点击
  await this.window!.webContents.debugger.sendCommand(
    'Input.dispatchMouseEvent', {
      type: 'mousePressed', x, y, button: 'left', clickCount: 1
    }
  )
  await this.window!.webContents.debugger.sendCommand(
    'Input.dispatchMouseEvent', {
      type: 'mouseReleased', x, y, button: 'left', clickCount: 1
    }
  )
  
  // 4. 等待页面响应（简单延迟）
  await new Promise(r => setTimeout(r, 1000))
  
  return { success: true }
}
```

#### 3.5.2 Agent Loop 实现

```typescript
const MAX_BROWSER_STEPS = 5
const BROWSER_AGENT_TIMEOUT_MS = 30000

async function runBrowserAgentLoop(
  userInput: string,
  toolArgs: Record<string, unknown>,
  config: LLMConfig,
  callbacks: AgentCallbacks
): Promise<string> {
  const startTime = Date.now()
  const steps: BrowserAgentStep[] = []
  let finalContent = ''

  // 1. 构造 URL 并打开页面
  const url = buildFinalUrl(toolArgs)
  const browseResult = await window.browser.open({ url })
  if (!browseResult.success) {
    return `浏览失败：${browseResult.error}`
  }

  // 2. 启用 CDP
  await window.browser.attachCDP()

  try {
    // 3. Agent Loop
    for (let step = 0; step < MAX_BROWSER_STEPS; step++) {
      if (Date.now() - startTime > BROWSER_AGENT_TIMEOUT_MS) {
        finalContent = await extractCurrentPageText()
        break
      }

      // 3a. 观察获取 AXTree
      const axTree = await window.browser.getAXTree()
      
      // 3b. 思考：LLM 决策
      const decision = await llmDecideAction(userInput, axTree, steps, config)
      
      // 3c. 安全检查
      if (!isActionSafe(decision, axTree)) {
        steps.push({ step, action: decision.action, result: 'Action blocked (unsafe)', timestamp: Date.now() })
        continue
      }

      // 3d. 执行
      let actionResult: string
      switch (decision.action) {
        case 'click':
          const clickRes = await window.browser.clickElement(decision.nodeId!)
          actionResult = clickRes.success ? `Clicked ${decision.nodeId}` : `Click failed: ${clickRes.error}`
          break
        case 'type':
          const typeRes = await window.browser.typeText(decision.nodeId!, decision.text!)
          actionResult = typeRes.success ? `Typed "${decision.text}" into ${decision.nodeId}` : `Type failed: ${typeRes.error}`
          break
        case 'scroll':
          const scrollRes = await window.browser.scrollPage(decision.direction!)
          actionResult = scrollRes.success ? `Scrolled ${decision.direction}` : `Scroll failed: ${scrollRes.error}`
          break
        case 'extract':
          finalContent = await extractCurrentPageText()
          steps.push({ step, action: 'extract', result: `Extracted ${finalContent.length} chars`, timestamp: Date.now() })
          break
        case 'done':
          finalContent = browseResult.text  // 使用初始页面文本
          break
      }

      steps.push({ step, action: decision.action, target: decision.nodeId, result: actionResult, timestamp: Date.now() })
      
      if (decision.action === 'extract' || decision.action === 'done') break
    }

    // 4. 如果 loop 结束但未 extract，提取当前页面
    if (!finalContent) {
      finalContent = await extractCurrentPageText()
    }
  } finally {
    // 5. 清理
    await window.browser.detachCDP()
    await window.browser.close()
  }

  return `已通过智能操作访问 ${browseResult.title}\n操作步骤：${steps.length} 步\n\n提取内容：\n${finalContent}`
}

/** 提取当前页面文本（Agent 模式下用 executeJavaScript，不走 CDP） */
async function extractCurrentPageText(): Promise<string> {
  // 用 CDP 关闭后或 CDP 仍开时，executeJavaScript 仍可用（POC-2 需验证）
  // 如不可用，改用 CDP Runtime.evaluate + 手动 UTF-8 处理
  return await window.browser.open({ url: '__current__' })  // 或直接 executeJavaScript
}
```

#### 3.5.3 安全检查

```typescript
const DANGEROUS_ELEMENT_PATTERNS = [
  /登录|注册|下载|购买|支付|删除|退出|注销|签约/i,
]

function isActionSafe(decision: BrowserActionDecision, axTree: AXNode[]): boolean {
  if (decision.action !== 'click') return true  // 只检查点击
  
  const target = axTree.find(n => n.nodeId === decision.nodeId)
  if (!target) return false
  
  // 1. 危险按钮检查
  if (DANGEROUS_ELEMENT_PATTERNS.some(p => p.test(target.name))) {
    return false
  }
  
  // 2. 域名安全：点击链接前检查 href（如果 AXTree 中有 url 属性）
  // 注：AXTree 的 link 节点通常不含 href，需要额外 DOM 查询
  // 简化处理：所有操作仍在同一窗口中执行，白名单域名限制由页面级保证
  
  return true
}
```

- type: 在元素中输入文本（需提供 nodeId 和 text）
- scroll: 滚动页面（需提供 direction: up/down）
- extract: 提取当前页面文本内容并结束
- done: 不需要更多信息，结束操作

## 规则
1. 优先点击与用户问题最相关的链接
2. 如果搜索框为空且需要搜索，先 type 再 click 搜索按钮
3. 如果当前页面已包含用户需要的信息，选择 extract
4. 不要点击"登录""注册""下载"等非内容按钮
5. 最多操作 5 步，请高效决策

## 输出格式
返回 JSON：
{"action": "click|type|scroll|extract|done", "nodeId": "xxx", "text": "xxx", "direction": "up|down", "reason": "决策理由"}`

## 六、关键设计决策

| 决策 | 选择 | 原因 | 替代方案 |
|------|------|------|---------|
| CDP 实现方式 | `webContents.debugger` + `Accessibility.getFullAXTree` | Electron 内置，0 体积 | Playwright（需额外浏览器） |
| Agent Loop 位置 | 渲染进程 `agentEngine.ts` | 与现有流程一致，复用 LLM 调用 | 主进程独立 Agent（需额外 IPC） |
| AXTree 简化 | 过滤 + 排序 + 50 节点硬上限 | 控制每次 LLM 调用 Token | 全量传给 LLM（Token 爆炸） |
| 文本提取与智能操作 | 同一 BrowserCDPService 实例 | 窗口复用，状态连续 | 分两个 Service（复杂度高） |
| 模式切换位置 | 输入框发送按钮上方 | 用户可见，操作便捷 | 设置页（层级太深） |
