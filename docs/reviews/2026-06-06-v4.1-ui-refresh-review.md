- **位置**：第 55-57 行
- **问题**：`transition-colors` 包含 `fill` 和 `stroke`，会应用到所有 SVG 元素
- **建议**：recharts 图表动画主要使用 `transform`/`opacity`，当前影响可控；如后续发现图表渲染异常，可缩小选择器范围（如排除 `svg *`）
